# ビジネス資料スライドプロンプトジェネレーター

提案書・企画書・報告書・研修資料の4タイプに特化した、AIスライド作成用プロンプトのジェネレーターです。
ぽちぽち選ぶだけで、NotebookLM / ChatGPT / Gemini / Claude に貼り付けられる高品質な構造化プロンプトが完成します。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー・ビルド不要の単一HTMLファイル）。

1. **資料タイプを選ぶ** — 提案書 / 企画書 / 報告書 / 研修資料。タイプごとに最適なスライド構成とライティングルールが自動セットされます
2. **基本情報を入力** — タイトル・想定読者・ゴール・伝えたい要点（空欄はAIが補完）
3. **スライド構成を確認** — 定番構成から不要な章をチェックで外して調整
4. **デザインを選ぶ** — 業種・トーン別の12プリセット（配色HEX・フォント・雰囲気がプロンプトに反映）
5. **出力オプション** — 貼り付け先（NotebookLM / 汎用AIチャット）、枚数、文体、情報密度、メッセージラインや話者ノートなどの仕上げ

「プロンプトを生成する」→「コピー」して、AIに貼り付ければ完了です。

## 設置方法

- そのままダブルクリックでローカル利用可
- WordPress固定ページ・レンタルサーバー・GitHub Pages などに `index.html` を置くだけで公開できます（外部依存なし）
